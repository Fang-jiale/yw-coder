# YWCodeR - AI 智能编程工具

一个基于 AI 的编程 IDE，像有了一个智能编程助手。

## 核心功能

| 功能 | 说明 |
|------|------|
| 🤖 AI 对话 | 向 AI 提问，获取编程帮助 |
| 🏗️ Builder 模式 | 用自然语言描述，AI 自动生成项目 |
| 💻 代码补全 | 智能提示代码 |
| 📁 文件管理 | 浏览、创建、编辑项目文件 |
| ⌨️ 内置终端 | 集成命令行工具 |

## 快速开始

### 1. 打开项目
点击「打开文件夹」加载你的项目

### 2. 向 AI 提问
点击右侧「新建对话」，输入你的问题

### 3. 生成项目
点击「Builder 模式」，描述你想要的应用

### 4. 使用终端
按 `Ctrl + `` 打开终端

## 常用快捷键

| 快捷键 | 功能 |
|--------|------|
| `Ctrl + N` | 新建文件 |
| `Ctrl + S` | 保存 |
| `Ctrl + F` | 查找 |
| `Ctrl + B` | 切换侧边栏 |
| `Ctrl + Shift + L` | 新建 AI 对话 |
| `Ctrl + `` | 打开终端 |

## 配置 AI

在设置中填写：
- **API Key** - OpenAI 密钥
- **模型** - 如 gpt-4

## 运行项目

```bash
npm install
npm run dev
```

## 技术栈

Electron + React + TypeScript + Monaco Editor
