# 修复 AI 文件编辑后未实际生效的问题

## 问题描述
AI 生成 `<file path="xxx">content</file>` 标签后：
- 代码显示写入成功（`success: true`）
- 但实际上文件没有被修改
- AI 继续基于"修改成功"的假设进行下一步操作

## 问题分析

### 根本原因
在 `aiStreamService.ts` 中，`</file>` 标签处理逻辑存在严重问题：

**第 975-993 行的代码：**
```typescript
try {
  await fs.mkdir(path.dirname(fullPath), { recursive: true });
  await fs.writeFile(fullPath, fileEditContent, 'utf-8');
  console.log(`[AIStreamService] File written successfully: ${fullPath}`);
} catch (error) {
  console.error(`[AIStreamService] Failed to write file: ${fullPath}`, error);
}

// 发送 tool_end 回调，标记文件操作完成
callback({
  type: 'tool_end',
  toolName: 'edit_file' as ToolName,
  toolResult: {
    tool: 'edit_file' as ToolName,
    success: true,  // ← 问题：无论写入成功还是失败，都返回 true
    data: { file_path: fileEditPath },
  },
  toolCallId: fileEditToolCallId,
});
```

**具体问题：**
1. 写入失败时，catch 只是 console.error
2. **没有设置任何失败标志**
3. **继续执行并返回 `success: true`**
4. AI 收到虚假成功信号

### 可能失败原因
根据 EPERM 错误历史，可能的原因包括：
- **Trae sandbox 限制**（当前终端会话被 sandbox 包装）
- **文件权限问题**
- **文件被占用**
- **磁盘空间不足**
- **路径不存在**

## 修复方案

### 步骤 1：在 `aiStreamService.ts` 第 975-1002 行添加错误处理
修改 `</file>` 标签处理逻辑，失败时返回 `success: false`：

```typescript
let writeSuccess = false;
let writeError: Error | null = null;

try {
  await fs.mkdir(path.dirname(fullPath), { recursive: true });
  await fs.writeFile(fullPath, fileEditContent, 'utf-8');
  console.log(`[AIStreamService] File written successfully: ${fullPath}`);
  writeSuccess = true;
} catch (error) {
  writeError = error as Error;
  console.error(`[AIStreamService] Failed to write file: ${fullPath}`, {
    message: error?.message,
    code: error?.code,
    errno: error?.errno,
    syscall: error?.syscall,
    path: error?.path,
  });
}

// 发送 tool_end 回调，根据实际结果返回状态
callback({
  type: 'tool_end',
  toolName: 'edit_file' as ToolName,
  toolResult: {
    tool: 'edit_file' as ToolName,
    success: writeSuccess,
    error: writeError ? `文件写入失败: ${writeError.message} (${writeError.code || 'unknown'})` : undefined,
    data: writeSuccess ? { file_path: fileEditPath } : undefined,
  },
  toolCallId: fileEditToolCallId,
});

// 如果失败，重置状态并继续
if (!writeSuccess) {
  inFileEditBlock = false;
  fileEditPath = '';
  fileEditContent = '';
  fileEditToolCallId = '';
  buffer = buffer.slice(fileEndIndex + 7);
  continue;
}
```
