# 离线环境适配检查计划

## 问题背景
编辑器在 Windows 10 云桌面（内网/离线环境）打不开，可能是缺少离线资源导致。

## 目标
检查并确保 Monaco Editor 及其他关键资源能够在离线环境下正常工作，不依赖外部网络资源。

## 检查清单

### 一、Monaco Editor 资源检查

#### 1.1 检查 Monaco Editor 加载方式
- [ ] 检查 `@monaco-editor/react` 配置
- [ ] 确认是否使用了 `loader` 配置
- [ ] 检查是否配置了 `paths` 或 `vs` 路径

#### 1.2 检查 Monaco 资源是否打包
- [ ] 检查 `node_modules/monaco-editor` 中的 min 文件
- [ ] 检查 vite 配置中是否正确处理 monaco 资源
- [ ] 确认 worker 文件是否被打包

#### 1.3 检查 CDN/外部资源依赖
- [ ] 搜索代码中是否有外部 CDN 链接
- [ ] 检查是否有 Google Fonts 等外部资源
- [ ] 检查是否有其他在线资源依赖

### 二、关键依赖资源检查

#### 2.1 字体资源
- [ ] 检查是否依赖在线字体
- [ ] 确认字体是否已本地打包

#### 2.2 图标资源
- [ ] 检查 Lucide 图标加载方式
- [ ] 确认图标是否完全离线可用

#### 2.3 样式资源
- [ ] 检查 Tailwind 是否完全离线构建
- [ ] 检查是否有外部 CSS 链接

### 三、Electron 主进程资源检查

#### 3.1 检查主进程是否有网络请求
- [ ] 检查 `index.ts` 是否有外部 API 调用
- [ ] 检查是否有自动更新检查（可能阻塞）

#### 3.2 检查协议处理
- [ ] 确认 `file://` 协议资源加载是否正常
- [ ] 检查 Windows 路径处理是否正确

### 四、修复方案（如发现问题）

#### 4.1 Monaco Editor 离线配置
- 配置 `@monaco-editor/react` 使用本地资源
- 确保 worker 文件正确打包和加载

#### 4.2 移除/替换外部资源
- 将 CDN 资源改为本地资源
- 确保所有资源都打包进 asar

#### 4.3 添加离线兼容处理
- 添加资源加载失败回退
- 添加离线检测和提示

## 预期输出

1. 资源依赖清单（内部 vs 外部）
2. 发现的离线环境问题
3. 修复后的配置变更
4. 验证离线环境可用的方法
