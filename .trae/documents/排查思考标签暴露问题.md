# 排查思考过程标签暴露问题

## 问题现象
- 第一段 assistant 输出时，思考过程可以被折叠显示
- 后续流式输出中，`<think>`、`<todo>`、`<task>` 等内部协议文本直接出现在正文区域

## 已实施的修复
1. `unifiedAgentStore.appendStreamingMessage` 现在每次 append 后调用 `parseMessageContent` 解析
2. `parseMessageContent` 函数提取 thinkingContent、todoItems、taskItems，返回 clean 的 visibleContent
3. `removeSpecialTags` 函数移除特殊标签

## 问题分析

### 可能原因 1：流式更新时只 append 原始内容，没有清理

**检查点**：
```typescript
// unifiedAgentStore.ts appendStreamingMessage 方法（约 L631）
appendStreamingMessage: (content) => {
  set((state) => {
    const raw = state.streamingMessage + content;
    const parsed = parseMessageContent(raw);
    state.streamingMessage = parsed.visibleContent;  // 应该存储清理后的内容
  });
},
```

### 可能原因 2：onStreamContent 事件直接发送未过滤的内容

**检查点**：
```typescript
// aiStreamService.ts 中 onStreamContent 事件处理
// 看 aiStreamService 是否在发送前过滤了标签
```

### 可能原因 3：ChatPanel 渲染时使用了错误的内容

**检查点**：
```typescript
// ChatPanel.tsx 中构建流式消息
const streamingMsg: Message = {
  content: streamingMessage,  // 应该已经是清理后的
  thinking: streamingThinking,
  ...
};
```

### 可能原因 4：AI 输出本身就带有标签

**检查点**：
- aiStreamService 的 `filterToolCalls` 方法是否被正确调用
- `filterToolCalls` 是否过滤了 `<think>`、`<todo>`、` <task>` 标签
