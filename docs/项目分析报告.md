## 核心功能模块

1. **AI 集成** - 支持 OpenAI API 调用，集成多种 AI 能力
2. **代码编辑器** - 基于 Monaco Editor (VS Code 同款)
3. **终端** - 集成 node-pty 实现嵌入式终端
4. **AI Agent** - Solo 模式自动执行代码任务
5. **对话系统** - AI 聊天界面，支持多轮对话
6. **文件服务** - 文件读写、搜索、重写
7. **构建系统** - 支持项目构建和运行

## IPC 通信

主进程和渲染进程通过 `IPC_CHANNELS` 进行通信，定义在 `src/shared/types.ts`。

### 主要通信通道

```typescript
// 文件操作
;(FILE_READ, FILE_WRITE, FILE_DELETE, FILE_LIST)

// 终端操作
;(TERMINAL_CREATE, TERMINAL_INPUT, TERMINAL_OUTPUT, TERMINAL_RESIZE)

// AI 服务
;(AI_CHAT, AI_STREAM, AI_TOOL_CALL)

// Agent
;(AGENT_CREATE_TASK, AGENT_EXECUTE, AGENT_STOP)

// 窗口管理
;(WINDOW_MINIMIZE, WINDOW_MAXIMIZE, WINDOW_CLOSE)
```

### 通信方式

- **主进程 → 渲染进程**: `webContents.send(channel, data)`
- **渲染进程 → 主进程**: `ipcRenderer.invoke(channel, ...args)`

## 注意事项

- 当前项目需要 Node.js 18+ 才能正常运行
- 开发模式下 Vite 运行在 5173 端口
- Electron 需要支持 GPU 的环境才能显示图形界面
